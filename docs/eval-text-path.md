# Text path on an emulated low-end phone

Generated by `cd pwa && npm run build && npm run test:perf` (`perf/text-path.test.js`). Do not edit by hand.

Production build in headless Edge with Chrome's "Slow 3G" profile (2 s round trip, 400 kbit/s each way) and the CPU slowed 4×. 5 runs each, message `sc-002`. The local server answers `/analyze` with the on-device engine (identical output to the server, see the parity tests); add the server p95 from [eval-report.md](./eval-report.md) for a real deployment. A real low-end Android phone on a real 3G connection is still the final check.
